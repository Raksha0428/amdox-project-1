# Cryptocurrency Time Series Analysis

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Streamlit](https://img.shields.io/badge/Streamlit-1.28.0-red.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

Real-time cryptocurrency price analysis and forecasting using ARIMA, LSTM, and Prophet models.

## Features
- Real-time data from Yahoo Finance API
- Interactive Streamlit dashboard
- Multiple forecasting models (ARIMA, LSTM, Prophet)
- Technical indicators and visualization
- Live price updates

## Installation
```bash
git clone https://github.com/YOUR_USERNAME/crypto-time-series.git
cd crypto-time-series
pip install -r requirements.txt
streamlit run app/streamlit_app.py
